# Web Development Rules

Build modern web applications using:

* HTML5
* CSS3
* Vanilla JavaScript
* Google Sheets + Apps Script as backend

## Core Principles

* Clean and maintainable code
* Responsive design (mobile-first)
* Accessible UI/UX
* Fast performance
* Security by design

## Security Requirements

* Never expose API keys, tokens, or secrets in frontend code.
* Store sensitive values in environment variables.
* Validate and sanitize all user inputs.
* Prevent XSS by using `textContent` instead of `innerHTML`.
* Implement rate limiting against spam and abuse.
* Use HTTPS only.
* Restrict CORS to trusted domains.
* Reject unauthorized API requests.
* Never commit secrets to Git repositories.

## Privacy Rules

* Collect only necessary user data.
* Do not store sensitive information unnecessarily.
* Minimize data retention.
* Respect user privacy by default.

## Code Standards

* Use semantic HTML.
* Organize CSS and JavaScript into separate files.
* Write modular and reusable functions.
* Add comments only when necessary.
* Prioritize readability over clever code.

## Performance

* Optimize images and assets.
* Minify CSS and JavaScript in production.
* Use lazy loading where appropriate.
* Keep bundle size small.


Generate production-ready code with security, scalability, and maintainability as first-class priorities.
