# ข้อมูลสำรอง

ไฟล์ในโฟลเดอร์นี้ถูกสร้างอัตโนมัติ **ห้ามแก้ด้วยมือ** เพราะจะถูกเขียนทับ

## นี่คืออะไร

สำเนาข้อมูลทั้งหมดของเว็บที่ดึงจาก Google Sheets ทุกคืน (ตี 2 เวลาไทย)
โดย GitHub Actions ใน `.github/workflows/backup-data.yml`

มีไว้เพราะข้อมูลจริงอยู่ในบัญชี Google บัญชีเดียว ถ้าบัญชีนั้นเข้าไม่ได้
ข้อมูลจะหายไปโดยไม่มีสำเนา ไฟล์ชุดนี้ทำให้ทุกคนที่ `git clone` repo
มีข้อมูลครบชุดติดเครื่องไว้เสมอ

## รันเองเมื่อไหร่ก็ได้

```
./scripts/backup-data.sh
```

## กู้ข้อมูลกลับยังไง

ไฟล์เป็น JSON ธรรมดา เปิดอ่านได้เลย ถ้าต้องสร้างชีตใหม่
ก็ใช้ไฟล์เหล่านี้เป็นต้นฉบับนำเข้าได้ทันที

อยากดูว่าข้อมูลเปลี่ยนอะไรไปบ้าง:

```
git log --follow -p data/backup/activities.json
```

## หมายเหตุ

- ดึงทั้ง `published` และ `archived` — endpoint ปกติของหน้าเว็บกรองเฉพาะ
  `published` ถ้าดึงแค่นั้นของที่เก็บเข้ากรุจะหายจากไฟล์สำรอง
- ตัดฟิลด์ที่ backend คำนวณเองออก (`*_url`, `photos`) เพราะสร้างใหม่ได้
  จาก `*_id` และทำให้ diff อ่านยาก
- เรียงลำดับคงที่ทุกครั้ง เพื่อให้ `git diff` แสดงเฉพาะสิ่งที่เปลี่ยนจริง
